+ 我為什麼喜歡週刊大於月刊
	+ 月刊的完成度相對高︰分鏡的視線編排、分鏡與對話框的構圖平衡、單話在預估的賣點上做了多少、是否達到最低的劇推進程度、在主要的賣點之餘又補上多少service等——我還沒有提到單行本閱讀的體感對吧
	+ 即使以雙作者組合達成不足，反而會產生磨合問題
		+ 即使是像約夢，我初期讀下來其實感覺有不少原作與作畫欠缺磨合時反而留下來的亮點：像是諾曼在逃獄篇有一幕露出陰險表情要反過來獵殺鬼的分鏡，我印象中是出水老師的即興
	+ 絕大多數週刊作者是把一個技術磨到頂後強行讓讀者接受其他相對粗糙的地方
		+ 又或者是強項點在文字的，它可能在構圖上就會走安全牌，鬼滅是經典的例子，我原本想提咒術，只是芥見在某個時期開始，戰鬥的擺拍變得有點強
		+ 網路上有尾田與松井老師在規劃分鏡的差異——我得替尾田老師平反，雖然我沒看OP，但尾田老師偏向塞滿滿的插畫風格，就很難在分鏡上作文章——你會發現松井也不是每一格都會畫背景，他在方面是平衡型，一兩格交代過場地後就會開始飆構圖——是說逃殿那部的分鏡也沒有暗殺教室玩得這麼花了
		+ 未必有是同個擅場就水火不容，以分鏡來說，藤本樹就很擅長用背景構圖與各種取鏡方式去再現各種氛圍，芥見很愛配合他亂切場景的習慣去配合他那些幾近意識流的台詞，這種沒有標準答案的風格選擇是漫畫最美妙的地方
	+ 週刊在很多設計因時間不足而相對仰賴直覺決定時，我反而會喜歡這種粗糙而曝露出來的東西
+ 我為什麼喜歡實體書
	+ 以週刊一年大概出四五集，一集有一個爆點的標準
		+ 收成單行本也比較容易安排成斷在hook，留給下一本處理兼拋出一個新hook
	+ 一年約四到五個爆點，約兩到三個月一個爆點
+ 我開始討厭笑點成為KPI
	+ 始作俑者未必是鬼滅，但[它]({{< relref "260910_10th_anniversary_kimetsu_holy_shit">}})是最開始的幾部
	+ 朱音落語有一段要求主角不能以讓人發笑來獲得觀眾的肯定
+ 我討厭約在咒術連載左右出現的弧形分鏡
	+ 之前在讀阿六時發現它也在弧，我對弧形分鏡的接受度真的很低
