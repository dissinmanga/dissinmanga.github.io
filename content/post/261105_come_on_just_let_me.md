不過要說的話，倒也不是最近，時不時就會掉進回憶漩渦，只是以前的我不怎麼把它們拿出來處理，並不是多大的事，但，講起來就有點羞恥。

音樂的自動播放軟體開始跳一些情歌，總讓我思索著，自己真的是很容易被催眠的人來著。我剛剛一邊吃飯一邊做頭腦體操一邊replay著這首[歌](https://www.youtube.com/watch?v=94-PAIMDhaQ)。

吃到差點把自己的臉當成屍體埋進飯裡。

然後現在又被情歌洗到進入微醺的狀態，加上今天整理筆記時，再一次理清有關於Ownership的一些概念，害我現在變得有點肢體。

你知道的，就那種，我又再更理解你一點了，的那種歡快。~~之前被chatgpt判成戀屍癖，所言不虛~~。

已經記不清上一次有這種感覺是什麼時候——說真的，我偶爾在午夜夢迴時，還是會想起那些在他身邊取暖的日子。不過，我根本不懂得如何調情，為此，我總感念著那些願意佇足在我身邊的他們，我是個boring guy。

我不喜歡表現得像個無賴（要確定耶），所以我總是壓抑著自己的這一面，也許只是需要再調整一下，也許。

寫作是件很奇妙的事，越寫我就越覺得，我寫出來的文章，大概是寫給別人看的，因為只要是寫給未來的自己看的東西，我總是會把精華抓出來，一個句子、一個大綱，像這樣：

```rust
use std::collections::HashMap;

impl Solution {
    pub fn group_anagrams(strs: Vec<String>) -> Vec<Vec<String>> {
        strs.into_iter().fold(HashMap::<_, Vec<_>>::new(), |mut m, i| {
            let mut t: Vec<char> =i.chars().collect();
            t.sort();
            m.entry(t).or_default().push(i);
            m
        }).into_values().collect()
    }
}
```

我可是在這個擠壓裡再次領悟了一些事情，雖然算法不太優，就讓我貼一下嘛。

只有這種沒有廢話的筆記才會讓我願意回頭去看，也許是求學時期留下的講義症候群遺毒使然。

說來，我會一直寫有關code的東西，只是因為syntax highlighting看起來很賞心悅目——突然想起前面好像有一篇把這個詞拼錯，所以跑回去改了。

但要說寫給別人看嗎？我又是個任性的人來著，於是，似乎也就只能是，為了準備給別人看而寫的，這個定位——其實現在也不用特意找理由支持，沒辦法我打字真的太快了[^1]，憑著睡前的微醺狀態硬上，根本也不用想要寫什麼，總是這麼亂七八糟。

也許，只是我在找個讓自己能待在這裡的理由。

我也許能憑著一點能高歌cause i'm in love的熱忱做著這些事，但我知道自己其實不夠格。我也知道我愛著這件事，與這件事愛不愛我，是兩回事。

吶，我這麼努力了，能再讓我多待一陣子嗎？
