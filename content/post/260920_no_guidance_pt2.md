+ 葬送的芙莉蓮[^1]
	+ > 這部作品，成功表現出了數量越來越多的單身高齡族群的願望……也就 是『自己擁有很多經驗，因此想要收一個會照顧自己，沒有血緣關係，雖然有天分但是缺乏 經驗，又會尊敬自己的徒弟』的這種心態。
	+ 我看到這個論點時一直笑，因為我最常在芙看到的心得是「這沒有一點歷練的話是看不懂的」
		+ 我原想回「老哥，這只要生命有別離的經驗，都會懂的好不好。」
		+ 但一來，我想起這是social media特有的潛意識囈語；二來，他所謂的「看不懂」，搞不好指的是長照這方面的議題
	+ 所以，我是贊同這個言論的，即使這部我真的看不動
	+ 我不是說喜歡芙的人就一定是這樣
		+ 芙的千年老妖設定有一個特質，它會帶出一種對現世的麻木，我覺得這對一些比較內傾，或比較耽溺在過去的人有著致命的吸引力
		+ 角色與劇情的設定有它核心的攻擊範圍，但這些設定也有相應的輻射範圍
+ 咒術迴戰
	+ 我在[這篇]({{< relref "260915_title_affects_you">}})提過芥見在筆觸集中在人們相互詛咒的場景上
	+ 但獨眼貓在特定場景的描寫上相當優秀，好比五條悟在雙玉篇沉浸在自身能力的成長時的顛狂，這在五宿戰中兩人不斷破壞設定，超乎常理的成長中也有高密度的描寫
	+ 所以你要說咒術粉絲都是這種會以「很壯的路人」詛咒虎杖（自己）的實力爛到沒能替最強分擔責任，又擅自將所有責任全盤扣在五條身上，五條一死就開始咒天咒地咒五條咒芥見下下的人
	+ 這又未免太過於滑坡
+ 日本漫畫在挖掘慾望的手段過於細節，細節到我慢慢不太願意去談論
	+ 這就像挖耳洞一樣，漫畫家這些是以職人的心態在服務讀者
	+ 我是以一個人對著空白螢幕在告解，幾乎是自由書寫的姿態在寫下這些文字
		+ 除了我本來就只能基於我的經驗去做解讀外
		+ 我甚至是會有些刻意地對一些我看不過眼的現象開砲
			+ 比如一群腐女拿著重金敗來的塑膠片大口狂吸，替自己立文青人設，轉頭judge宅男沉浸在女優宅音的畫面，我看幾次也難以習慣，明明都是在網路上交流精神假屌的使用心得。
			+ 我曾經以為同是天涯淪落人，應該會懂，即使是social media的囈語，這個弱弱相殘的景象終究是讓我困惑大於理解
			+ 還好只要脫離追星圈就不用看到這些人——只是這些言論我終究是吃下去，變成我的一部份了
	+ 在談論這類相對內傾的議題時——雖然我喜歡這種提供人向內看的契機——無可避免地會面臨到人的異質性，這種感覺很容易與「我不屬於這個群體」、「只有我這樣想嗎」的感受連結，非常讓人不舒服[^2]
+ 你看鬼滅了嗎？
	+ 挑戰別人的價值觀本來就會讓人不舒服
+ 以憤怒為驅動力
