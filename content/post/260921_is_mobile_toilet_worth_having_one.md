+ 人需要一個攜帶式心理廁所嗎？
	+ 我[提過]({{< relref "260916_move_to_hugo">}})在手機上以obsidian與這個blog對接
		+ 雖然有若干技術問題難以正面解決
		+ 零碎的想法也能先丟進來
+ 公共衛生與心理衛生
	+ Blog作為空白螢幕、儲思盆的功能，該不該推薦
		+ 就不會像次子的媽媽一樣懷疑丈夫是外星人，無法愛著自己的小孩，只能訴諸超自然的寄託
+ 杞人憂天
	+ 原子大便
		+ 因為屢次在過去的文章提過，就不太想要另開一篇新文章聊的事
			+ 我一直很想聊，就像是魔術師與觀眾，我站的位置是那個相對靠近魔術師，試著用自己的經驗解釋魔術師戲法的人
			+ 普通觀會覺得我在煞風景
				+ 就像是在旁邊解釋笑點的人很冷場
			+ 有魔術師背景的觀眾會覺得我在公三小
			+ 有一說是這是ragebait
				+ 我不太在意我會被當無知的人，但因為之前在social media看煩了，所以想統一說，對，我就無知
				+ 這也許會激起有變魔術經驗的人花時間發一篇[反駁文]({{< relref "260915_title_affects_you">}})
		+ 這應該要切成原子大便重覆撿回來使用嗎？——你瞧，這篇文又降低了我專開一篇文聊這件事的
	+ 我偶爾會按一下隨機看看以前的自己寫了什麼
		+ omg這些文真的是我寫的嗎？我被奪舍了吧？那時敲鍵盤的人不是我
		+ 光[偏頭痛]({{< relref "260914_talkinshit">}})跟失眠就會讓一個人性格大變
		+ 憤怒會讓人很有力量，即使有些憤怒的底色是悲傷；不是所有人都有消化表層攻擊性的能力，你不能期待把挫折以憤怒的形式丟出去時，會有其他人看穿、接近，並同理你的悲傷
+ 公開發佈圖的是什麼
	+ 如果沒有切膚之痛，就不要發一篇文
	+ 就像是人被刀切的那個感覺，也需要教才知道那是「痛」；切膚之痛也是需要體驗的
+ 公開發佈的結案感
	+ 在切成原子大便的狀況下
		+ 結案感很明顯，我甚至覺得是超級完美的PKM
	+ 我只想要Blog公開發表的結案感，但我其實不那麼想浪費別人的關注力
	+ 是不是一種顧及個人心理衛生而犧牲公共衛生的舉措？
	+ 原子大便有結案感，亂七八糟的大便會有結案感嗎
